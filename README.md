ដើម្បីធានាថាកូដចាស់ៗ និងប្រព័ន្ធទូទាត់ប្រាក់ KHQR មិនមានបញ្ហា ឬ Regression មុនពេលបន្ថែមមុខងារថ្មីៗ លោកអ្នកអាចដំណើរការ Check Verify បាន ៣ វិធីងាយៗ៖

### វិធីទី១៖ ចុច Double-Click លើឯកសារ `verify.bat` (ងាយស្រួលបំផុត)
